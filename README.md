## Selected projects

NestJS API uses Prisma and PostgreSQL for member relationships, user-scoped data, and consent-aware discovery and sharing. Public source includes migrations, focused service tests, and CI checks for lint, tests, and builds.
- **[Vending Machine](https://github.com/TeodorTod/vending-machine):** Angular application separates Signals-based product and transaction state from initial HTTP loading. Integer-cent arithmetic and bounded backtracking handle exact change with finite coin inventory. Purchases validate before synchronous stock and coin updates; tests cover failure paths and a case where greedy change selection fails.
